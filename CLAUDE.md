# Econxvis — conventions

Interactive visualizations for the econometrics lectures by Lukáš Lafférs.
Sister project of [Microvis](https://github.com/LukasLaffers/microvis): same setup, same look, same rules.
Published with GitHub Pages; each tool gets a stable URL that can be linked from the lecture handouts (PDF).

## Layout

```
index.html              start page: one tile per tool, by handout; generated by tools/build-site.cjs, do not edit by hand
STYLE.md                the Microvis style kit guide (principles, tokens, components, writing, safeguards): follow it
shared/style.css        the whole look: identical to Microvis (from the style kit) + an "Econxvis" section at the end
                        with the colours of the regression figures (--fig-*)
shared/ui.js            identical to Microvis's, except the name (window.Econxvis) and the --fig-* colours in theme()
shared/vendor/          Plotly 2.35.2 and KaTeX 0.16.9 with their licenses
tools/catalog.cjs       site title, lead, footer, and the tools grouped by handout, in reading order
tools/glyphs.cjs        the 64 x 64 drawing on each tile
tools/build-site.cjs    writes index.html and the header link and previous/next links of every tool page
tools/previews.cjs      hover previews of the tiles: node tools/previews.cjs "ols-projection:#plot3d"
<tool-name>/            one folder per tool, kebab-case, e.g. ols-projection/
  index.html, app.js, model.js (UMD, pure math), test-model.cjs, style.css (optional), SPEC.md (optional),
  preview.webp, preview-dark.webp
```

## Rules

- The look is Microvis's (see `STYLE.md`). To pick up a change in Microvis, copy its `shared/style.css` over ours
  above the "Econxvis" section, and its `shared/ui.js` with the two renames; raise the version tag.
- Plain HTML, CSS and JavaScript. No framework, no bundler, no npm install, no CDN. Pages work offline and as local files.
- Minimal design: Helvetica/Arial (no serif, also not in plot labels), square corners, hairlines, no shadows, no
  coloured stripes, no gradients. Black and white plus one blue (`--brand`) for what can be clicked or moved;
  subject colours (the handout figures) only inside figures and their captions.
- Text is short and lets the figure speak: a one-sentence tile description; "How to read this" is the idea in two or
  three sentences, then a short list of things to try. Engaging but academic, precise. Name buttons as labelled,
  in bold; never "below" / "on the right".
- Every tool: works on a phone (controls above the figure), has "How to read this", labels its axes, shows the key
  numbers live, shows errors in the status banner, supports light and dark mode.
- Add each new tool to `tools/catalog.cjs` and its drawing to `tools/glyphs.cjs`, run `node tools/build-site.cjs`,
  then `node tools/previews.cjs "<tool>:<selector of the main figure>"` and build again.
- Keep math in `model.js` and test it in Node against independent calculations (brute-force minimisation, explicit
  matrix formulas, textbook special cases). Never change model math without updating the tests.
- Use the notation of the lecture handouts (table below).
- Our own CSS and JS are linked with a version tag (`?v=N`, now 1). Raise it in all pages whenever a shared file changes.
- No lecture numbers on the pages or the start page (unlike Microvis): sections and page eyebrows carry the title
  of the handout, e.g. "Regression basics". No course code, university name or contact details.
- `.nojekyll` stays in the root.
- Before publishing: every page loads without console errors; no horizontal scroll at 375px; no unneeded
  scrollbars at 1440/1280/1024/768px; screenshots checked in light and dark, desktop and phone.
- Write all code ourselves; Microvis (ours, MIT) is the reference.

## Notation (must match the handouts)

| Object | Symbol |
|---|---|
| model | $y = X\beta + \varepsilon$, $y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$ |
| OLS estimator | $\hat\beta = (X^TX)^{-1}X^Ty$ |
| fitted values, projection matrix | $\hat y = X\hat\beta = Py$, $P = X(X^TX)^{-1}X^T$ |
| residuals, residual maker | $\hat\varepsilon = y - X\hat\beta = My$, $M = I - P$ |
| mean, deviation from the mean | $\bar y$ (the vector $\bar y\,\mathbf 1$), $\bar\varepsilon = y - \bar y$ |
| sums of squares | $TSS=\sum(y_i-\bar y)^2$, $ESS=\sum(\hat y_i-\bar y)^2$, $RSS=\sum(y_i-\hat y_i)^2$ |
| goodness of fit | $R^2 = 1 - RSS/TSS = ESS/TSS = \mathrm{cor}(\hat y, y)^2$ (with an intercept) |

Colours of the regression figures (lecture 1, slide "Geometry: It is a simple projection"), in `shared/style.css`:
$y$ black `--fig-y`; $\hat y$ blue `--fig-yhat`; $\hat\varepsilon$ / RSS red `--fig-resid`; $\bar y$ green `--fig-ybar`;
$\bar\varepsilon$ / TSS yellow `--fig-ebar`; $\hat y-\bar y$ / ESS purple `--fig-ess`; the column space `--fig-plane`.
